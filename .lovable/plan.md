# DM Ventilation website redesign

## Goal
Replace the blank project with a modern, practical homepage for DM Ventilation Systems. The page will preserve the current site’s useful catalogue and contact information while making product discovery and enquiries much easier on desktop and mobile.

## Visual direction
- Build the selected **Project board bento** composition faithfully.
- Use `#2D3694` as the primary brand colour, supported by deep blue, neutral paper, white surface, charcoal, grey, and a restrained amber accent.
- Use Sora for headings and Manrope for body text.
- Keep the presentation engineered and compact: small corner radii, clear borders, dense readable grids, and restrained motion.
- Generate a cohesive set of realistic industrial equipment and installation images for the main visual, three featured products, and completed-system panel.

## Homepage content and functionality
- Add a sticky, mobile-friendly header with section navigation, brochure access, and a prominent enquiry action.
- Create the first-view product board with company positioning, product/system counts grounded in the current catalogue, quotation and brochure actions, and a real machinery image.
- Add three visual featured-product cards plus quick links for additional core equipment.
- Add a scannable systems and capabilities area covering industrial ventilation, dust extraction, fume scrubbing, and kitchen ventilation.
- Present the company’s established-manufacturer story without inventing certifications, response times, office locations, opening hours, client names, or unsupported performance claims.
- Add industry coverage, brochure access, and the verified Bahadurgarh address, phone numbers, and email addresses from the existing site.
- Make phone numbers and email addresses directly actionable. Until a new brochure file is supplied, brochure actions will point to the existing brochure page rather than a fake download.
- Use in-page navigation for this homepage so every visible action has a working destination; no empty or placeholder links.
- Add a compact footer with corrected current copyright text.

## Quality and accessibility
- Provide descriptive image text, visible keyboard focus, semantic headings and landmarks, and reduced-motion support.
- Ensure long product names, contact details, controls, and grids fit cleanly across mobile and desktop widths.
- Add homepage-specific search and social metadata for DM Ventilation Systems.
- Verify the rendered page at desktop and mobile sizes, test navigation/contact actions, and confirm the preview finishes without errors.

## Technical details
- Implement the homepage in the existing TanStack Start route and keep the scope frontend-only.
- Define the selected direction’s colours, typography, radii, and motion as semantic tokens in the global Tailwind v4 stylesheet.
- Load Sora and Manrope through document-head links.
- Record the resulting frontend structure and asset approach in the project’s technical notes.
